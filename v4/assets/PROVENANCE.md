# Locally bundled authored assets

- `materials/oak-albedo.jpg`: new generated seamless natural-oak material, guided
  by the approved finish. It is not an image of the user's home or a reference
  crop. Normal/roughness maps are derived by `tools/materials.py`.
- Fabric and cabinet support maps: original deterministic warp/weft material
  generation in `tools/materials.py`. `door-ash.jpg` is a pale ash remapping of
  the authored grain. No private photo is an asset input.
- `models/sofa-tailored.glb` and `models/curtains-draped.glb`: original custom
  geometry, authored and exported with `tools/hero_assets.py` in Blender 4.3.
  No downloaded furniture models or private pictures are embedded.
- Renderer dependency: Three.js r180, MIT; see `../vendor/THREE-LICENSE.txt`.
  Only required module/addon files are bundled. No remote runtime requests.

Model dimensions are design/photo fits, not surveyed product specifications.

## Integrated corrected-reference v3

- Oak colour/normal/roughness refinements are regenerated from the authored PR #5
  blob by `tools/refine_materials.py`; it suppresses harsh fibres, adjusts grain
  scale/contrast and neutralizes the cast. No new home photograph is a texture.
- `plaster-color.jpg` / `plaster-normal.webp` are original low-contrast mineral
  support maps generated by that script. Existing kitchen/entrance maps are kept.
- `bedroom-soft.glb` is custom Blender geometry from `tools/bedroom_assets.py`:
  upholstered bed/headboard, draped cream bedding/pillows and closed taupe drapes.
- Living curtains retain the existing `tools/hero_assets.py` pipeline with softer
  irregular tension folds. The sofa GLB itself is unchanged.
- RoundedBoxGeometry / Reflector are the matching Three.js r180 MIT addons.
  Bathroom/lamp/vanity/wardrobe geometry is authored in `room-details.js`.

No reference image or private photograph is embedded in these assets.
